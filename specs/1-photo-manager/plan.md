## 功能概述

PhotoMan 是一个完全本地化的桌面图片管理应用，帮助用户高效地组织、浏览和管理海量个人照片。核心价值在于提供隐私安全、性能卓越、用户体验流畅的图片管理解决方案，支持10000+张图片的流畅浏览，完全本地存储，跨Windows/macOS/Linux三大平台。

关键特性：

- 原地索引，不破坏用户文件组织
- 智能标签和相册系统
- 强大的搜索和筛选
- 完善的数据保护（回收站、自动备份）
- 并发扫描支持
- 自动重复检测
- 中英双语界面

## 宪章合规检查

在开始实现前，确认本功能符合项目宪章的以下原则：

- [x] **性能优先**: 虚拟滚动、缩略图缓存、异步加载，支持50000+图片库
- [x] **用户体验至上**: 3次点击完成操作，丰富快捷键，拖放支持，15分钟学习曲线

- [x] **可扩展性**: 模块化架构、插件系统预留、图片格式处理模块化
- [x] **跨平台兼容**: 使用Electron/Tauri跨平台框架，适配三大平台UI规范

## 技术上下文

### 技术栈选择

基于项目需求和宪章原则，采用以下技术栈：

**桌面框架**: Tauri 2.0

- **理由**: 包体积小（<10MB）、性能优异、内存占用低、符合"性能优先"原则
- **优势**: Rust后端安全高效、系统WebView、快速启动（<1秒）
- **备选**: Electron（如遇到不可克服问题可回退）

**前端框架**: React 18 + TypeScript 5

- **理由**: 组件化、类型安全、生态成熟、性能优化方案丰富
- **UI库**: Ant Design 或 Material-UI（支持暗色主题）

**状态管理**: Zustand

- **理由**: 轻量简洁，适合本项目规模

**数据库**: SQLite (rusqlite)

- **理由**: Rust原生集成、高性能、类型安全、跨平台
- **用途**: 存储图片元数据、标签、相册、设置

**图片处理**: image (Rust crate)

- **理由**: Rust原生、高性能、内存安全、与Tauri完美集成
- **备选**: Sharp（通过Node sidecar，用于Rust库不支持的格式）

**EXIF处理**: kamadak-exif (Rust) + exifr (前端降级)

- **理由**: Rust原生解析、性能优异

**文件系统监控**: notify (Rust crate)

- **理由**: Rust原生、跨平台、性能好
- **备选**: chokidar（前端降级）

**虚拟列表**: react-window

- **理由**: 轻量高效，满足需求

**国际化**: react-i18next

- **理由**: React生态标准，支持中英双语

**测试**: 用户手动验证

- **理由**: 优先功能实现，快速迭代

### 关键技术点

1. **高性能渲染**

   - 虚拟滚动：使用react-window处理大量图片
   - Web Worker：后台执行耗时操作（哈希计算、EXIF解析）
   - requestIdleCallback：利用空闲时间生成缩略图
   - 图片懒加载：Intersection Observer API

2. **并发控制**

   - 扫描与UI操作隔离：扫描在独立进程/Worker
   - 数据库锁机制：避免并发写入冲突
   - 任务队列：限制并发缩略图生成数量（CPU密集型）

3. **数据一致性**

   - 原子操作：文件操作使用事务
   - 乐观锁：处理元数据并发更新
   - 定期校验：检测文件移动/删除

4. **性能优化**

   - SQLite索引：图片路径、哈希、标签关联
   - 缓存策略：LRU缓存最近访问的图片数据
   - 批量操作：减少数据库往返
   - 图片预加载：预测用户浏览方向

5. **跨平台兼容**

   - 路径处理：使用path模块统一处理
   - 原生模块：条件加载平台特定代码
   - UI适配：检测平台应用对应样式

6. **文件哈希**
   - 算法：SHA-256（安全性高）
   - 策略：首次扫描计算并缓存
   - 增量：仅对新增/修改文件计算

| 风险                     | 影响程度 | 可能性 | 缓解措施                                             |
| ------------------------ | -------- | ------ | ---------------------------------------------------- |
| Rust学习曲线陡峭         | 中       | 高     | 核心逻辑用TS、Rust仅用于性能关键部分、提供模板和培训 |

| 大图库（50000+）性能下降 | 高       | 中     | Rust性能优势、数据库索引优化、虚拟滚动、早期测试     |
| SQLite数据库损坏         | 高       | 低     | 自动备份、WAL模式、Rust内存安全、修复工具            |
| 跨平台文件路径问题       | 中       | 低     | Rust标准库统一处理、充分测试、单元测试覆盖           |

| 缩略图缓存占用过多磁盘   | 低       | 高     | 缓存大小限制、LRU淘汰、用户可清理、设置显示          |
| 并发扫描与操作冲突       | 低       | 中     | Tokio异步运行时、WAL模式、Rust并发安全               |
